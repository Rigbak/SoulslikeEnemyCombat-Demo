# Soulslike Enemy Combat Demo

A playable Windows build of the demo level of **Soulslike Enemy Combat**, the Unreal Engine plugin for enemy combat AI: enemies that keep their distance, circle, take turns, parry, dodge and counter, and bosses that switch movesets mid-fight. You need no Unreal Engine to play it.

**[Download SoulslikeEnemyCombatDemo.zip](https://github.com/Rigbak/SoulslikeEnemyCombat-Demo/releases/latest/download/SoulslikeEnemyCombatDemo.zip)** (Windows)

The link always serves the newest build. Every build is listed under [Releases](https://github.com/Rigbak/SoulslikeEnemyCombat-Demo/releases).

## What is in it

- **Patrol, pit and sparring zones**, each showing another side of the enemy AI.
- **A boss fight** with telegraphed attacks and punish windows.
- **Enemies that answer you:** they parry, dodge and counter, and the two-handed enemy dodges half the time after a run of your blows.
- **Combat roles** that decide who attacks, who flanks and who waits, so a group takes turns.

## How to run it

1. Download the ZIP.
2. Right-click it and choose **Extract All**. A demo started from inside the ZIP cannot find its files.
3. Open the extracted folder and run `SoulslikeEnemyCombatDemo.exe`. Its first start can install Microsoft's Visual C++ runtime.

**Windows protected your PC?** The demo is not code-signed, so Windows SmartScreen can stop the first start. Choose **More info**, then **Run anyway**.

## What you need

- Windows 10 or 11, 64-bit
- A graphics card with DirectX 12
- About 1 GB of free disk space for the ZIP and the extracted demo
- A keyboard and mouse, or a gamepad
